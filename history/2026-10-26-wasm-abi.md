# Wasm 双向 ABI 与初始化预算修复

日期：2026-10-26；对应 [12 Wasm 宿主](../12-wasm-host.md)、[21 测试策略](../21-testing-strategy.md)
和 [19 M2](../19-roadmap.md)。

## 缺陷与修复

恢复原有字符串返回用例时，保留原 ANSWERS 组件字节不变，得到
`expected 1 result(s), got 0`；根因是生产调用总传入空结果数组，不是该组件返回区指针错误。
调用现在先校验完整签名，按 WIT 类型读取字符串或 outcome，并在返回前执行 canonical post-return；
清理失败不能报告成功，错误结果签名在执行 guest 指令前被拒绝。
输入以借用字符串传入，避免在进入 canonical lowering 前再克隆一份宿主字符串；未据此声称整体性能预算达标。

Host linker 原先手写签名，把 outcome variant 当 tuple、枚举当整数、设备 record 列表当字符串列表，
并错误处理部分 tuple、option 和多参数含义。
现在从生产 WIT 生成 Host trait 与注册，适配器将类型值交给同一个 HostCalls 闸门；
传输与 action 等参数映射保持实际业务含义，非法布尔值、JSON 或设备种类不再静默替换成默认值。

完整生产 WIT world 的真实组件初始化又暴露了 fuel 为零的问题；
Store 现在具有独立的有限启动 fuel 与 epoch deadline，沿用初始化内存限制，业务调用重设自身预算。
正常构造和无限循环构造分别验证允许与终止，未以无限 fuel 绕过初始化失败。

Host 调用计数改为记录真正导入调用的尝试，包括无会话与权限拒绝；
单纯调用一次 Guest 入口不再增加 Host 计数。

## 结构与测试方法

编译策略、编译产物、实例资源状态和 Guest 调用分别由私有模块负责，公开后端接口保持原入口。
Host 记录桩由普通闸门测试与真实 Wasm 测试共用，避免再复制一套 Host 实现。

WIT world 测试使用 `wit-parser` 和 `wit-component` 嵌入生产类型信息并生成真实组件，
没有手抄第二份导入类型，也无需外部 wasm-tools 命令或安装 wasm32-wasip2 目标。
覆盖完整 world 链接、错误导入类型、五种 outcome 入口成功与失败、重复调用的 post-return、
清理失败、错误返回类型、真实导入读取及无会话、无权限、纯匹配禁止写入。
拒绝测试同时断言宿主实际未执行操作，避免只检查返回错误。

旧调查原文已从当前规范移到 [历史快照](./wasm-abi-observations.md)；
其中“夹具 ABI 错误”“没有真实 Host 调用”等推断只反映当时的调查。

## 未覆盖范围

本次证明宿主 ABI 边界与相应预算、闸门行为，不等于 Rust 插件 SDK 构建、安装、
生产路由与平台动作的完整验收，不包含移动设备运行或性能预算达标声明。
同步 Host IO 不能被 epoch 抢占，需其自身 deadline 与取消的完整证据，当前计算超时测试不作替代。
D1–D5 与整体里程碑仍有未完成项，继续以 [当前路线图](../19-roadmap.md) 为准。
