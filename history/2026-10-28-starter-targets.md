# 2026-10-28 · Starter 的目标电脑选择

## 当前契约

UI `device.list` 需要当前页面的 `device:list` 授权，只返回已配对且未屏蔽的设备。
四字段视图保留 `online: false`，不再由注入层静默过滤离线设备；发现但未配对的设备不可见。
最多返回 256 项，超限明确拒绝，不用截断结果冒充完整列表。

Starter 声明此权限，新增目标电脑面板：只列出 Windows、macOS、Linux 电脑，保留离线状态，
展示名称与规范 UUID，初始不选中任何电脑。刷新后保留仍存在的明确选择，目标消失则清空，
不自动替换为第一台。列表经过类型、数量、名称长度、规范 UUID 和重复 id 校验。

刷新只有一个在途调用；8 秒超时后显示错误且仍等待原调用结束，不叠加重试。
页面隐藏、离开及销毁清空选择并丢弃迟到回复；错误不回显原生异常内容。
设备配对、在线与操作授权是不同维度，本面板不表示已获远端操作许可。

## 尚未完成

本轮不代表新目标选择界面的真实手机或视觉排版验收已通过。
真实 Windows 已验证空列表和刷新；非空电脑选择与离线变化由自动测试覆盖，尚未连接第二台实际设备验收。

Core 的插件事件服务目前处理本地投递；远端打开链接、选中文本和触摸板不能仅靠接上按钮完成。

超时、重复请求和真实执行结果，再将 Starter 的动作接入；不得把排队或手机本地打开当作电脑执行成功。
