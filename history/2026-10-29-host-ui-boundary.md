# 2026-10-29 · 宿主界面与插件功能分离

## 用户决策

主程序不固定内置具体插件功能；已接收、已完成、插件标识与调用记录等状态展示和预览数据可以保留。
当前规范落在 `28 R56`，并同步应用仓库 README 与 AGENT。此次没有新增首页插件插槽或快捷入口机制。

## 四页检查

| 页面 | 本轮处理 |
| --- | --- |
| 首页 | 移除分享输入、分享剪贴板，以及接收文件的打开、定位和删除操作；保留连接情况、任务记录、授权/拒绝、传输取消和接收文件元数据 |
| 设备 | 移除发送文字/文件按钮、发送弹窗、原生选择器调用与发送成功提示；保留发现、扫描、配对和取消配对 |
| 插件 | 保留安装、权限、更新、同步、移除和打开独立插件页面，均属于宿主管理；未添加具体插件动作 |
| 设置 | 保留应用、身份、传输安全策略和诊断配置，均属于宿主管理 |

移除入口时同时删除关联前端状态、函数、中英文文案和过时行为测试，不以隐藏开关保留旧界面。
共享内核、插件运行时及其平台能力仍是插件运行基础设施；此次没有改动 Rust 源码或插件仓库。

## 验证

- 更新后的全量前端测试 373 项通过；以新的中英文宿主边界回归替代已删除业务入口的旧测试。
- 验证完成状态、`@synra-plugin/github` 和 `01HQ00000000000000000TRACE1` 仍展示；接收文件列表只查询记录，不触发文件操作。
- 全量 ESLint 零警告、类型检查、生产构建和 8 项 shapes 检查通过；宿主前端调用的不同命令从 53 减为 47，README 同步更新。
- 独立浏览器窗口核对四页；中英文首页和设备页在 390×844 视口下主内容区宽度均为 390px，无横向溢出。
- 调用记录原先会撑宽手机内容区，改为受宽度约束并按需换行，保留完整插件及调用标识。
- 默认特性 `cargo build --locked -j1` 通过，本机开发版已嵌入最新前端资源；既有大分块和 PDB 命名碰撞警告仍保留。

Rust 源码未变化，未重复运行既有 Rust 单测；浏览器预览验收不代替原生实机交互。
