# 应用首次配对交互（2026-10-26）

承接[共享首次配对入口](./2026-10-26-first-pairing.md)，应用替换旧 token 请求及六位码提示，
使用同一个已登记网络身份中的 PairingService，宿主不另行实现同意、授权或持久化规则。
当前接口见 [08 §2.2](../08-ipc-and-frontend.md)，完整范围仍以 [19 §0.2](../19-roadmap.md) 为准。

## 行为与边界

任一设备可导出公开证书邀请；另一设备选择目标后显式导入邀请，展示包含证书和临时端口的应答；
首台设备选择应答方并显式导入应答，建立受限 mTLS 并交换既有会话绑定的同意和持久回执。
界面说明必须通过可信带外路径取得内容，发现名称和地址不证明身份。
导入始终绑定所选设备 id，没有自动批准发现证书或旧 token 回退。

应用发现服务实际写入 devices_seen，并不更新出站 Host 的发现表，因此连接命令从真实写入表读取路由；
返回应答中的端口替换发现端口，认证仍校验明确导入的证书。缺少有效路由明确拒绝连接。
应用命令不持有数据库或 Host 锁执行 TLS，可能涉及持久写入的命令在 Tauri 阻塞线程执行。

IPC 删除 PairingPrompt、pairingRequested、pairingResolved 及旧 request/respond 命令，
使用共享 PairingSnapshot 和 pairingUpdated 事件；状态命令没有任务时返回 null。
任务字段中的 Option 保持必有键与显式 null，JS 镜像守卫核对阶段集合、字段类型及可空性，
并以错误阶段、遗漏 null、改为可选键和错误时间类型的变异验证守卫能发现漂移。

单个全局事件订阅触发权威重读，store 串行合并读取并丢弃被后续命令或事件失效的响应；
页面只保存选择 id 和导入输入，名称来自设备 store，配对进度来自后端任务。
导航回来会重读状态，监听应答仍可取回；取消按原任务代次执行，终态保留供用户查看。
到期提示由后端终态驱动，不由前端计时器宣布成功或授权。
预览假内核没有原生身份，明确拒绝生成邀请或开始握手，不制造可用证书或成功授权。

## 验证

应用生产命令测试使用两份未预置对端授权的真实文件数据库和真实 TLS，
完成双方配对后重开数据库并核对持久授权；发现端口故意设为错误端口，
确认受限端口来自应答而身份校验仍绑定证书。
拒绝测试覆盖错误目标身份、不存在任务代次的取消、无原生身份和非法 id。
界面测试覆盖导出、导入、所选设备变化清空输入、返回页面后仍展示应答、取消、过期与结构化错误，
store 测试覆盖旧读响应与新命令竞争、合并读取及错误恢复。
全局事件测试另行验证配对进度使用传入 client 重读，旧事件不能覆盖较新的后端任务。

阶段门禁：应用后端全量 320 项与 doctest、IPC 全量 123 项与 doctest、
应用无默认特性的全部目标 Clippy、默认 Tauri 编译、修改 Rust 文件的格式检查均通过。
前端完成全量回归后按影响复用结果，修正组件夹具并补充事件与错误竞态测试，
最终受影响模块 15 项通过，合计覆盖当前 337 项；Vue 类型检查、完整生产构建、全量 lint 和 8 项形状守卫通过。
JS 各包及脚本合计 187 项测试通过，另通过全量 lint、类型检查、消费者类型检查、14 项形状守卫与文档类型检查。
12 项 Rust 架构守卫通过，包含应用调用方、声明 MSRV、96 份文档链接及文档数量声明。
Core 仅改 IPC，未改动的网络、存储及业务模块复用上一阶段结果，没有重复执行全工作区测试。
生产构建仍有主包超过 500 kB 的体积提示，本轮未把构建产物体积作为已解决的性能问题。

## 剩余范围

Android 原生密钥后端及设备运行验证、显式身份修复和平台恢复仍未完成，D1 保持开发中。
运行时 socket 和快照不跨进程恢复；未完成预留仍需到期或显式撤销，不能自动晋升授权。
双方最终提交不是跨设备原子事务，失败侧不得从残留日志自动补发授权。
本轮不证明原生密钥后端的持久性，不包含性能基准、平台视觉矩阵或发版工作。
