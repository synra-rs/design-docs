# 09 · 视觉语言与组件约定

## 1. 沿用什么，调整什么

沿用深色暗紫主题、Carbon 图标、现有字体、Ant Design Vue、UnoCSS 与 `@synra/theme`。
不照搬 Folo 的橙色/浅色，不另引 shadcn/Radix，不复制其 React 组件、图标或内容素材。
调整的是信息层次、占位、显示时机与操作分组；先删重复内容，再决定颜色和字号。

## 2. 文本层次

| 角色 | 建议表现 | 例子 | 约束 |
| --- | --- | --- | --- |
| 页面标题 | 现有 `text-xl`，适当字重 | 设备、插件、设置 | 每页一个，不配默认介绍段 |
| 区域标题 | `text-sm`/`text-base`，中等字重 | 已配对、权限 | 不靠超大留白制造层次 |
| 主内容 | 现有14–16px等效级别、`ink` | 名称、值、主要状态 | 不用 dim 表示可点击主入口 |
| 说明/元数据 | 现有12–14px等效级别、`inkDim` | 版本、时间、简短帮助 | 不能继续用 opacity 降至不达标 |
| 技术值 | `font-mono`＋次级色，必要时换行 | ID、trace、路径、能力名 | 仅真实机器字段，不给普通中文整段等宽 |
| 错误/待决定影响 | 可读正文＋状态图标/文字 | 需要重新授权、签名失败 | 不因属于说明就一律变成最淡最小字号 |

根字号保持默认，不把14px根字号作为“紧凑模式”。字号/间距从现有 token 或 utility 取，不散落新的像素常量。
已有 `inkDim=#8c82a6` 在当前主题的页面/面板/浮起面有对比度测试；若改变 token，要在 `synra-js` 真相源修改并重算相关背景。
“不明显”通过内容精简、位置和字重实现，不能把错误/必要安全说明压暗到难以读取。

## 3. 间距、行高与空状态

优先使用现有4/8倍数间距。建议普通管理行垂直内边距8–12px，主副两行约56–72px；触摸区最小44px，必要时自动增高。
这是正常文本下的目标区间，不是强制固定高度；长名称、缩放、系统字体变大必须能增长。
区块间距通常16–24px，页面头与列表之间避免连续多个大 `gap` 加上默认段落 margin。

| 场景 | 目标空状态 |
| --- | --- |
| 全新应用、尚无设备/插件 | 一个轻量图标、短标题、必要一句说明、一个主要入口 |
| 页面中的空分组 | 单行次级文字，或不渲染无意义分组 |
| 筛选无匹配 | “没有匹配项”＋清除筛选 |
| 加载未完成 | 静态骨架，不提前画无数据 |
| 读取失败 | 错误原因/重试，不显示空列表冒充成功 |
| 不支持的能力 | 对应区域说明，其他区域照常可用 |

不修改组件库全局 Empty 来迁就所有情境；由页面决定“首次引导”还是“局部空状态”，选对组件尺寸/形式。

## 4. 面、边框与状态

列表是一块连续工作面，不把每个对象都装进高对比圆角卡片；分隔线只区分真实组/区域。
普通连接摘要不使用 `floating` 材质，遵守 [28 R26、R43](../28-app-ui.md)：浮起层才使用相应玻璃/阴影。
hover 用轻背景，selected 用稳定选中面，focus 用可见焦点环；三者互不覆盖成无法辨认的同一高亮。
状态至少有文字/形状，颜色只辅助。正常“运行中/在线”优先轻文字或状态点，非必要不铺一大片绿底。
warning 只用于需要关注的变化，普通“有更新”不与“新增权限/签名异常”使用同等告警面积。

## 5. 按钮层次

| 层次 | 用法 |
| --- | --- |
| 页面主要动作 | 一个清楚入口，如安装插件/配对设备；不是每个区域都有主色大按钮 |
| 行主要动作 | 打开、配对、处理当前请求；按对象决定是否可用 |
| 次要动作 | 文本/图标按钮，具备名称与 hover/focus 反馈 |
| 更多菜单 | 管理低频项；按钮常显但弱化，不能弱到看不出可点击 |
| 危险动作 | 菜单末尾/详情危险区域，执行前明确确认，正常页不常驻红色删除按钮 |

保存、重试、检查更新不是同一个概念，使用准确动词；按钮忙碌时既有 loading 也阻止重复操作。
无图标的文字按钮不用为了窄屏变成难猜的符号；空间不足换行或进更多。

## 6. 文案压缩示例

| 当前表达/模式 | 建议 | 理由 |
| --- | --- | --- |
| 已连接＋设备已就绪 | 已连接 | 重复的信息只留一次 |
| 空的正在传输插图＋管理设备 | 暂无进行中的传输 | 无传输并不需要管理设备 |
| 默认完整配对教程 | 点击配对后只显示当前一步说明 | 步骤跟随任务而非每次进入页面 |
| 插件标识/版本/发布者全部标签化 | 列表短摘要，详情有完整标签和值 | 减少重复字段名而不丢数据 |
| “已拒绝：无”“已授予：无”每项常驻 | 详情显示完整权限结果 | 正常行只体现是否有待处理 |
| 同时常驻“从目录安装/注册表安装/筛选已安装” | 安装流程 / 发现分类 / 已安装筛选 | 让上下文决定输入含义 |
| That did not work | 操作具体原因＋下一步 | 失败可恢复，而不只是态度表达 |

这些例子是文案目标，不以改翻译表代替数据和布局调整。页面上的插件描述是第三方内容，不能一律强行改成中文。

## 7. 中英文词汇与可达性

| 中文 | 英文 | 语义 |
| --- | --- | --- |
| 首页 | Home | 一级页面 |
| 设备 / 已配对 / 附近设备 | Devices / Paired / Nearby | 信任与发现分组 |
| 插件 / 已安装 / 发现 | Plugins / Installed / Discover | 管理与查找 |
| 打开 | Open | 打开独立插件 UI，不暗示重新启用 |
| 查看详情 / 更多操作 | View details / More actions | 对象信息与操作入口 |
| 任务 / 进行中 / 接收记录 | Tasks / In progress / Received files | 不承诺尚未实现的持久历史 |
| 权限 / 调用记录 | Permissions / Call history | 授权与能力审计，不混作任务结果 |
| 取消配对过程 / 取消配对 | Cancel pairing / Unpair | 正在握手与撤销已建立关系 |

所有新增宿主文案、图标名称、tooltip、确认按钮进入现有消息目录，两语言同批完成，格式化时间复用本地化工具。
Tooltip 不能是屏幕阅读器名称的唯一来源；aria-label 应有当前对象与动作的可理解关系，如“打开 Starter”。

## 8. 与现有组件的映射

| 设计原语 | 优先组件 | 本地封装的职责 |
| --- | --- | --- |
| PageHeader / 分组工具栏 | 现有布局 utility＋AButton | 标题、动作槽、换行，不读业务 store |
| 对象行 / ActivityRow | AList、ATag、AButton、ASwitch、AProgress | 统一排版与可见性，不管理第二份任务状态 |
| RowActions | ADropdown＋AMenu＋ATooltip | 共享动作、名称、busy、事件边界 |
| 对象详情 | ADrawer＋ATabs/ADescriptions/ACollapse | 焦点、对象选择、延迟内容与窄屏布局 |
| SettingRow | 表单标签＋输入/开关/选择 | label关联、必要说明、错误位置 |
| HelpText / HelpTrigger | 现有 HelpText＋ATooltip/APopover | 非必要说明按需出现 |
| ConfirmAction | AModal；简单无额外选择可沿用APopconfirm | 对象、后果、默认选择、确认中状态 |
| 状态和错误 | AAlert、现有ErrorNotice/CrashNotice | 作用域、去重、恢复入口 |

先在一两个真实页面抽出重复结构，不一开始建设通用 schema 表单引擎或万能详情框架。
样式通过现有唯一 ConfigProvider/theme 适配器进入；不在组件里复制 Folo 色值、写第二个主题或用 `!important` 压组件库。

## 9. 动效与稳定性

使用已有 duration/easing token，hover/focus 只做短淡入/背景变化；尊重 reduced motion。
行高、按钮槽和主标题位置保持稳定，不用“hover 时从零宽度展开”把整行推挤。
状态改变可以局部说明，不自动滚动到页首、抢选中对象或弹出窗口；只有用户明确动作才移动上下文。
