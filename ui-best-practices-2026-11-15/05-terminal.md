# 终端与 synra://wire
## 8. 终端 / `synra://wire` 下一版

### 8.1 产品定位

`synra://wire` 是一个全局只读线缆监视器，帮助用户回答“刚刚发生了什么”，不是 REPL、命令执行器，也不是第二个任务中心。

它应采用开发者工具的“Dock/Sheet”思路：入口全局固定，打开后拥有独立工具栏、独立滚动、独立暂停和复制状态；关闭后不取消后台配对、传输或插件任务。

### 8.2 目标布局

```text
┌──────────────────────────────────────────────────────────────┐
│  ● LIVE                                                   [×] │
├──────────────────────────────────────────────────────────────┤
│  All   Sent   Received   Peer ▾   Search  [Pause] [Clear]    │
├──────────────────────────────────────────────────────────────┤
│  22:18:41.871  →  7f3a9c21  _synra.pair.request       128B │
│  22:18:42.191  ←  7f3a9c21  _synra.pair.response       42B │
│  22:18:42.771  •  7f3a9c21  dial 192.168.0.42:47100       │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│  LIVE · 3 new lines                         [Jump to latest] │
└──────────────────────────────────────────────────────────────┘
```

顶部栏进一步收敛为“● LIVE”与右侧关闭按钮。不要在顶部栏展示 `synra://wire`、发送/接收计数、行数或额外标题；暂停、清空、复制等低频操作进入过滤行的更多菜单，避免终端头部变成第二个工具栏。

### 8.3 视觉规则

- 终端使用不透明近黑背景，避免半透明终端和毛玻璃面板叠加后在 WebView 中变成脏灰块。
- 时间、字节数和辅助状态使用低亮度灰；事件名保持高可读性。
- `→`、`←`、`•` 分别表达发送、接收和生命周期；颜色只按方向/状态分配，不按事件名彩虹化。
- 字体使用稳定的等宽字体，行高约 1.35；字号以 12–13px 起步，在移动端允许放大。
- 终端工具栏使用普通按钮和可访问名称，不能把图标或快捷键作为唯一入口。
- 有新内容但用户正在回看历史时，停止自动滚底并显示“跳到最新”。

### 8.4 交互规则

1. 打开：焦点进入关闭按钮或第一个可见控制；终端不会自动抢走正在输入的焦点。
2. 关闭：`Esc`、关闭按钮和遮罩都能关闭；焦点回到原触发按钮。
3. 暂停：暂停写入显示，但不丢弃计数；恢复后继续接收新行，不伪造暂停期间的历史。
4. 过滤：All / Sent / Received 和 Peer 过滤只影响展示；不能让后台事件丢失。
5. 复制：复制当前缓冲或用户选择，按钮短暂显示结果；失败明确提示。
6. 搜索：`Ctrl/Cmd-F` 在终端内查找，结果可以逐个跳转；搜索不改变事件顺序。
7. 诊断关联：如果一行有 `traceId`、设备或任务 ID，点击后在右侧/下方显示元数据，不直接展示 payload 正文。
8. 只读边界：当前只读终端禁止输入。未来如果需要交互会话，必须显式显示会话来源、目标、权限、运行状态和停止动作。

9. 触摸滚动：终端 viewport 必须允许垂直触摸平移，使用 `touch-action: pan-y`、`-webkit-overflow-scrolling: touch` 和受控的 overscroll；终端容器不能用父级事件阻止 `touchmove`。在 Android WebView 上用真实手指上下滑动回看日志，不能只验证滚动条拖动。

### 8.5 数据和性能

- 保留现有事件总线，不建立第二条订阅通道。
- 大量传输块按时间窗口节流；终端显示关键帧和摘要，不逐块刷屏。
- `fit()` 和 ResizeObserver 只在容器尺寸稳定后执行，resize 事件需要 debounce。
- 终端代码和样式继续懒加载，普通用户只看首页时不承担 xterm 体积。
- 无流量时只显示一句短提示，不使用插画或引导按钮。
- 终端导出属于诊断产物，复制只读日志；不默认记录或展示 payload 正文。
